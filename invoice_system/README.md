# 发票自动整理系统

这个第一版用于本地批量整理发票文件，把 PDF、图片发票整理进
`<项目目录>/发票模板.xlsx`，并另存为月度发票管理表。

## 使用方式

### 网页拖拽上传

```bash
python3 <项目目录>/invoice_system/web_app.py
```

启动后打开：

```text
http://127.0.0.1:8765
```

可以一次选择多个 PDF/图片，也可以直接拖进去。也支持两种按报销人分组的上传方式：

- 选择整个文件夹：顶层文件夹名会作为报销人，例如 `张三/发票1.pdf`。
- 上传 ZIP 压缩包：ZIP 文件名会作为报销人，例如 `张三.zip` 里的发票都会归到张三。

也支持“一个组统一汇总”的新格式：选择整个总文件夹，文件夹里放一个汇总表 Excel，
PDF 可以混放在一起，也可以放在子文件夹里，但 PDF 文件名需要是发票号码。系统会先读取
汇总表里的发票号码，找到对应 PDF，再从 PDF 票面识别购买方公司，最后继续生成原来的
公司分组结果。

推荐结构：

```text
某组5月报销/
├── 汇总表.xlsx
├── 26437000000164334912.pdf
├── 26957000000132762573.pdf
└── 其他发票/
    └── 26957000000132763138.pdf
```

汇总表至少要有“发票”或“发票号码”列；如果还有“报销人、项目、金额、开票日期、备注”，
系统会直接沿用这些列。没有匹配到 PDF 或 PDF 购买方识别不出来的发票会进
`购买方公司待核对`；如果 PDF 确实已经按公司放在子文件夹里，系统会把文件夹名作为
待核对兜底，但优先使用 PDF 票面识别出的购买方公司。

如果上传的是散文件，则继续使用页面里的“报销人”输入框。也可以按一个报销人一批上传：
填好报销人姓名，上传这个人的所有发票并提交；提交成功后页面会清空文件列表和报销人，
保留月份/批次名称，方便继续录入下一个报销人。

同一个总报销批次名称会持续汇总。例如先用 `5月报销` 上传张三的发票，再保持
`5月报销` 上传李四、王五和其他员工的发票，系统会扫描这个批次下所有报销人的全部发票，
然后按购买方公司拆分输出结果。A 公司的所有员工、所有类型发票会进入 A 公司文件夹；
B 医院的所有员工、所有类型发票会进入 B 医院文件夹。
每次提交后结果目录会重新生成，只保留最新的公司分组结果。上传文件会保存在：

```text
<项目目录>/uploads
```

生成的 Excel、待核对 CSV 和按发票号码重命名后的 PDF 副本会按购买方公司分文件夹保存在：

```text
<项目目录>/outputs
```

这是本地网页，不会把发票上传到外部服务器。

### 命令行整理已有文件夹

```bash
python3 <项目目录>/invoice_system/invoice_manager.py \
  <项目目录>/4月产5月报销 \
  --reimburser "报销人姓名"
```

默认输出在月份文件夹旁边，并按购买方公司分文件夹，例如：

```text
<项目目录>/outputs/4月产5月报销/某某科技有限公司/
<项目目录>/outputs/4月产5月报销/某某医院/
```

每个购买方公司文件夹里会包含这个公司自己的报销汇总 Excel、待核对 CSV 和 PDF 发票：

```text
某某科技有限公司/
├── 某某科技有限公司4月产5月报销汇总.xlsx
├── 某某科技有限公司4月产5月报销汇总.待核对.csv
└── 发票PDF/
    └── 25442000000012345678.pdf
```

PDF 会按识别到的发票号码命名。如果购买方公司没有识别出来，会放进
`购买方公司待核对` 文件夹；如果发票号码没有识别出来，会使用
`待核对_序号_原文件名.pdf`，方便后续人工检查；如果号码重复，会自动追加 `_2`、
`_3` 避免覆盖。

微信认证费发票通常不会在票面显示具体认证账号。处理这类发票时，可以先把 PDF 文件名
改成认证账号名称，系统会自动把文件名写入备注栏，例如 `认证账号：某某公众号`。

## 当前会填入的模板列

- 序号
- 报销人
- 项目
- 金额
- 开票日期
- 发票：写入文件名，并添加到原始发票文件的超链接
- 备注：自动识别不足时标记待核对

话费/通讯费报销会把识别到的手机号写入备注，例如 `号码：13800138000`。
腾讯微信认证类发票会优先归类为 `微信认证费`。

## 识别逻辑

程序优先读取同名 `.txt` 文件，其次调用本机可用工具：

- PDF 文本层：`pdftotext`
- 扫描型 PDF：`pdftoppm` 转图片后调用 `tesseract`
- 图片 OCR：`tesseract`

如果本机暂时没有 OCR 工具，程序仍会从文件名里识别金额、发票号码、常见项目词，
并生成待核对 CSV，方便人工补全。

## 建议安装的 OCR 工具

如果要真正自动识别扫描型 PDF 和图片，建议安装：

```bash
brew install poppler tesseract tesseract-lang
```

如果 Homebrew 提示 `/opt/homebrew` 不可写，先在 macOS 终端执行：

```bash
sudo chown -R $(whoami) /opt/homebrew /opt/homebrew/Cellar /opt/homebrew/Frameworks /opt/homebrew/bin /opt/homebrew/etc /opt/homebrew/include /opt/homebrew/lib /opt/homebrew/opt /opt/homebrew/sbin /opt/homebrew/share /opt/homebrew/var
```

输入电脑登录密码后，再执行安装命令。

安装后重新运行同一条命令即可。后续做小程序或 App 时，可以把
`invoice_manager.py` 里的 `extract_text`、`parse_*` 和 `write_workbook`
拆成后端 API 复用。
